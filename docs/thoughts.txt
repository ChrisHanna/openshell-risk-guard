OpenShell Risk Firewall adds risk-based conditional access for autonomous agents via OpenShell's native extension interfaces (`SupervisorMiddleware` on the data plane and `GatewayInterceptor` on the control plane). It evaluates otherwise-authorized actions against an approved task baseline and risk signals—destination, originating executable, HTTP method/route semantics, velocity/fan-out, and whether the endpoint is credential-bearing—without ever exposing raw secret values. OpenShell remains the enforcement point; the risk layer can only attenuate access by alerting or denying (`behavioral_risk_denied`) and latching high-impact restrictions for the current policy epoch while surfacing quarantined requests for operator review. Over an observation window, it generates explainable least-privilege policy-hardening diffs verified with OpenShell's Z3 containment prover (`openshell-prover`); recommendations never auto-apply, and any broader access requires starting a new, explicitly authorized policy epoch.
